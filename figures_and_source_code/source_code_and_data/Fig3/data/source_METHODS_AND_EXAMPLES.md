# SRH-PGG A1/A2：处理方法与通俗实例

更新日期：2026-11-03。

## 1. 四张图各自回答什么

| 图 | 比较对象 | 所回答的问题 |
|---|---|---|
| m实验A1 | 从左到右m=3、2、1，alpha固定0 | 改变m时，点、边两类个体在所考察r范围内的合作水平分别怎样变化？ |
| alpha实验A1 | 从左到右alpha=0.5、0.25、0，m固定1 | 改变连接方式时，点、边两类个体的合作水平分别怎样变化？ |
| m实验A2 | 同样三个m类别 | 各类型个体分布在哪些超度区间？不同超度个体的合作水平怎样？ |
| alpha实验A2 | 同样三个alpha类别 | 同上，但比较alpha实验。 |

每张图按P_l=0、0.25、0.5、0.75、1分为五列。

SRH中每条超边都包含4个节点，所以每个个体的“平均参与超边阶数”都是4。直接沿用ORH的这个横坐标会使所有个体落在同一个位置。按用户确认，本次A2改看**超度，即一个人参加多少个群组**。

例如：甲参加3个四人群组，乙参加20个四人群组。他们接触的平均群组规模都是4，但超度分别是3和20。SRH A2比较的是后一个差别。

## 2. 先分清两个不同的参数

- **m或alpha**：控制网络结构，是三个待比较的类别。两个实验分开处理。
- **r=R/4**：控制博弈收益，是每个类别内需要覆盖的41个取值，0、0.05、…、2。

因此，SRH中“对41个参数条件等权平均”是指对41个r平均。不能把alpha=0、0.25、0.5混在一起平均，否则就失去了对三种结构的比较。

本次读取New_PGG.zip中m和alpha目录各自的old_generator_results。m目录使用全部615份TXT；alpha目录使用指定三类的615份，排除其余3690份。每组保留全部41个r，包括合作率为0或1的条件，不选择性删除低合作、高合作或吸收态结果。

两项实验合计使用1230份TXT、2460000条节点记录。每个参数组合只有一份TXT，未将不同r当作独立重复实验。

## 3. A1：一个点、一个箱体、一条线分别是什么

先固定某一个结构类别和P_l，例如：m=1、alpha=0、P_l=0.5。

**第一步：在一个r条件下，分别计算两类个体的平均合作率。**

以真实文件r=1为例，该网络有966名点策略个体。把这966人的第5列合作率加起来，再除以966，得到0.864352401656。这是A1里的一个蓝色小圆点；它代表这一条件下全部点策略个体的平均合作水平，不是某一个人的合作率。

同一文件中的边策略个体单独计算，得到一个橙色小方点。两类个体的分母分别使用各自实际人数，不能都除以2000。

**第二步：对41个r重复上述计算。**

每个类型得到41个小散点。将这41个合作率用于计算箱体、中位数及上下须。箱体表现不同促进因子下结果的分散程度，不是独立重复实验的置信区间。

**第三步：将41个合作率等权平均，得到黑色均值菱形。**

上述m=1、P_l=0.5的点策略箱体，均值为0.562795832421，中位数为0.864352401656。两者不同是正常的：较低r的低合作结果会拉低均值。

**第四步：连接同一种类型在三个结构类别下的均值。**

蓝线连接点策略的三个均值，橙线连接边策略的三个均值。连线顺序为m=3→2→1或alpha=0.5→0.25→0。不同类型之间不连接，小散点也不逐个连接。

小散点的横向随机偏移仅为了减少遮挡。均值连线使用箱体中心，不使用抖动后的散点位置。

## 4. A2上图：先合并人数，再算同类型内部的比例

先按超度把个体分为八个区间：1–3、4–7、8–15、16–31、32–63、64–127、128–255、≥256。两个实验使用完全相同的区间。

这些区间随超度增加而加宽，使高超度的长尾也能纳入。最后一段没有有限上界，所有高超度个体都保留。本次最大超度达到2343，仍包含在≥256段中，没有截掉。

以 **m=1、P_l=0.5、点策略、超度8–15** 为例：

1. 找到这组条件下41份r文件。
2. 每份文件只选点策略个体，数出其中超度8–15的人数。
3. 把这41个人数相加，得到3662条个体记录。
4. 把41份文件内全部点策略人数相加，得到41166条个体记录。
5. 上图这一色块的高度为 **3662÷41166=0.088956906185，约8.896%**。

这里没有先计算每个r的百分比再求平均。分子和分母先分别合并，然后只做一次除法。

每个点策略个体都会且只会进入一个超度区间，所以该根点策略柱的八段合计100%。边策略柱使用自己的同类型总人数，同样合计100%。

“41166条个体记录”来自41次不同条件的网络，不表示某一个网络里有41166人，也不能把不同文件中相同编号的节点当成同一个被长期追踪的人。

纯点群体只画N柱，纯边群体只画L柱；不存在的类型不填0柱。

## 5. A2下图：每个r先求区间均值，再对41个r等权平均

还是看 **m=1、P_l=0.5、点策略、超度8–15**。

在每一个r下，先筛选这个区间中的点策略个体：

- 对这些人的第4列求算术平均，得到这个r下的区间平均超度。
- 对这些人的第5列求算术平均，得到这个r下的区间平均合作率。

下面只列出5个r帮助理解；实际计算使用完整41个r：

| r | 同类型总人数 | 超度8–15的人数 | 区间内平均超度 | 区间内平均合作率 |
|---:|---:|---:|---:|---:|
| 0 | 1011 | 100 | 10.600000 | 0.000000 |
| 0.5 | 1008 | 69 | 10.550725 | 0.000000 |
| 1 | 966 | 94 | 10.191489 | 0.895679 |
| 1.5 | 1022 | 92 | 9.706522 | 0.986784 |
| 2 | 1020 | 85 | 10.423529 | 0.990382 |


例如r=1时，这个区间有94名点策略个体：平均超度为10.191489，平均合作率为0.895679。注意，这是94人的区间均值；A1在同一r下的0.864352，是全部966名点策略个体的均值。

完成41个r的计算后：

- 将41个区间平均超度相加再除以41，得到横坐标 **10.2743495498**。
- 将41个区间平均合作率相加再除以41，得到纵坐标 **0.57935425494**。

所以，下图最终画的是一个点 **(10.27435，0.57935)**。它汇总了该类别、该P_l、该类型、该区间在全部41个r下的表现。

**上图和下图采用不同汇总方式，是因为回答的问题不同。** 上图问所有纳入记录中有多少比例属于这个区间，所以合并人数；下图问覆盖整个r范围时这个区间平均表现怎样，所以让每个r贡献一个区间均值，权重相同。下图不会因为某个r恰好多几个人就给它更大权重。

## 6. alpha实验的真实例子

选择 **alpha=0.5、m=1、P_l=0.5、边策略、超度8–15**，方法完全相同。

| r | 同类型总人数 | 超度8–15的人数 | 区间内平均超度 | 区间内平均合作率 |
|---:|---:|---:|---:|---:|
| 0 | 1013 | 257 | 10.708171 | 0.027237 |
| 0.5 | 1030 | 276 | 10.500000 | 0.047367 |
| 1 | 982 | 256 | 10.464844 | 0.830676 |
| 1.5 | 1021 | 275 | 10.712727 | 0.853354 |
| 2 | 1015 | 274 | 10.755474 | 0.869388 |


上图：41个r中，该区间的边策略记录合计10807条，同类型全部记录合计40870条，所以色块高度为 **10807÷40870=0.264423782726，约26.442%**。

下图：将41个r的区间平均超度、区间平均合作率分别等权平均，得到 **(10.6569736414，0.545234472324)**。

同一组条件下，A1的边策略均值菱形为 **0.547699326956**。A1包括全部边策略个体；A2的这个点只包括超度8–15的边策略个体，因此两者不必相同。

## 7. 三个人数指标与不显示的区间

以上m实验点策略、超度8–15的例子：

| 指标 | 数值 | 通俗解释 |
|---|---:|---|
| n_nodes_total | 3662 | 41个r下这个区间的人数加起来。 |
| n_nodes_mean | 89.3170731707 | 3662÷41，平均每个r约89.32人。 |
| n_nodes_min | 69 | 41个r中，人数最少的那一次有69人。 |
| n_type_total | 41166 | 41个r下，全部点策略人数加起来。 |
| node_share_pooled | 0.0889569061847 | 3662÷41166，是上图色块高度。 |

人数均值可以有小数，因为它不是某一次仿真的人数。

下图沿用ORH的规则：一个区间必须在**每一个r下都至少有20个该类型个体**，才显示点线。上述区间最少69人，因此显示。

如果41个r中某一次只有8人，即使其余条件有很多人，也不在下图显示。如果某一次为0人，则不能把这次合作率当成0；两个下图均值留空。若相邻显示点中间存在不合格区间，线在此处断开，不跨缺口连线。

所有不显示的区间仍保留在CSV中，也全部计入上图。下图不显示不代表该区间合作率为0，更不代表网络里没有高超度节点。

本次m实验显示74个A2点，alpha实验显示105个A2点。门槛是沿用的展示规则，不是置信区间或显著性检验。

## 8. 横坐标为什么使用对数刻度

横坐标存储和绘制的数值仍是上面得到的实际平均超度，没有换成区间中点，也没有先取log再计算平均。

对数刻度仅改变横向距离：3→6、6→12、12→24在图上占相同宽度；alpha图中的24→48也占同样宽度，便于同时看清低超度和较高超度个体。比如10.27435仍画在10.27435的位置，不会变成log(10.27435)。

本次将m实验A2的横坐标范围从2.7–55收紧为2.7–24，刻度为3、6、12、24；alpha实验继续使用2.7–55和3、6、12、24、48。同一张A2内的五个下排面板仍采用相同的横轴范围。下图纵轴均为0.25–0.75，包含全部显示点；m实验显示点的合作率约为0.25659–0.62895，alpha实验约为0.36798–0.63296。

## 9. SRH结构比较应如何理解

**m实验的平均超度没有固定。** 本次原始数据中的超边数和平均超度为：

| m | 超边数 | 平均超度 |
|---:|---:|---:|
| 3 | 1999 | 3.998 |
| 2 | 2995 | 5.990 |
| 1 | 5989 | 11.978 |

这是原始生成代码在固定N、G和mh时改变m的结果。本处理保留这些差别，没有按平均超度归一化或重新构图。因此m实验展示的是改变该生成参数后的结构与合作差异，不能仅凭本图将全部差异归结为“在固定平均超度下增加异质性”。

alpha实验固定m=1，三类均有5989条超边，平均超度均为11.978。它与m实验的结构控制条件不同，两项实验分别呈现。

两个目录包含205个相同的m=1、alpha=0参数组合，但对应TXT文件均不相同。本次始终使用各自目录中的记录，没有把两个目录合并成重复样本。因此m图的m=1曲线与alpha图的alpha=0曲线出现小差异并不意味着数据处理错误。

A2描述“参与群组数量”与“个体合作水平”的关联。未控制节点年龄、局部组成等变量，也没有从本图作单独的因果判断。
