# Fig5 · SRH MPD：超度组成与合作水平

这是用户提供的 `SRH_new_figure.rar` 中的新增 A2 图，比较增长参数 m=3、2、1，固定随机连接概率 η=0。A2 是来源包的分组名，论文图号为 Fig5。

上排五列分别为 P_l=0、0.25、0.5、0.75、1；每个结构类别中，N、L 分别表示实际存在的 Node、Link 类型。八个颜色区间对应超度 [1,4)、[4,8)、[8,16)、[16,32)、[32,64)、[64,128)、[128,256)、[256,+∞)。色块比例由全部 41 个 δ=0、0.025、…、1 条件中的人数合并归一化；各类型柱高度为 1。

下排横轴是区间内个体的实际平均超度，采用以 2 为底的对数坐标显示；均值计算仍在原始尺度。纵轴是同区间的平均合作率（范围 0–0.5）。两个均值均为先在每个博弈参数条件内取类型/区间平均，再对 41 个条件等权平均。只有每个条件均至少有 20 名同类型个体的区间绘制下排点线；其他区间仍保留在上排及原始 CSV 中，缺失值不补零，不跨缺失区间连线。Node 使用实线实心圆、Link 使用虚线空心三角；结构参数按项目蓝橙绿映射保持同值同色。

代码和数据保存在同一子目录：`data/plot_data.csv` 为原样复制的源表，`data/source.json` 记录来源与字节哈希，`data/source_reference.pdf` 保留来源成品，`figure.json` 记录当前配置。`draw.py` 调用公共 `paper_srh_a2.py` 绘制本地成品；`plot.py` 是含交付和预览刷新的统一入口。

成品为 160 × 108 mm、两排五列，编号 (a)–(j)，8 pt Times New Roman，实际线条 0.6 pt。PDF 为矢量图，PNG 由交付流程以 600 dpi 从 PDF 渲染；上排极小比例段仅填色、不加边框，避免白色分隔线遮盖真实小色块。纵轴小数保留前导零。

在项目根目录运行：

```powershell
uv run python "正文图/Fig5/plot.py"
```
