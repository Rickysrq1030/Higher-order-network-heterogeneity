## 1. 四张图分别回答什么

| 图 | 从左到右的类别 | 所回答的问题 |
|---|---|---|
| m实验A1 | m=3、2、1；固定alpha=0 | 改变m时，点、边两类个体在所考察b范围内的合作水平怎样变化？ |
| alpha实验A1 | alpha=0.5、0.25、0；固定m=1 | 改变连接方式时，两类个体的合作水平怎样变化？ |
| m实验A2 | 同样三个m类别 | 各类型个体主要位于哪些超度区间？参加群组数量与合作水平有何关联？ |
| alpha实验A2 | 同样三个alpha类别 | 同上，比较alpha实验中的三种结构。 |

每张图按P_l=0、0.25、0.5、0.75、1排列五列。P_l是设定的边策略概率，实际人数由TXT中的个体类型确定，混合群体不强行凑成预定人数。

SRH的每条超边都是四人群组，因此这里看的是**参加多少个群组（超度）**。例如甲参加3个四人群组，乙参加20个四人群组，平均群组规模都是4，但超度分别为3和20。A2按后者分组，使用节点记录第4列。

## 2. 哪些文件进入计算

- m：读取`New_MPD/m/data`的615份TXT，m=1、2、3全部保留。
- alpha：读取`New_MPD/alpha/old_generator_results`中alpha=0、0.25、0.5的615份TXT；其余3690份不纳入。
- 两个实验都覆盖b=0、0.025、…、1，共41个值；每个结构类别和P_l组合均有完整41份TXT。
- N=2000、G=4、mh=3；总演化长度1000000 MCS，合作率取TXT已保存的末期100000 MCS平均值。

合计使用1230份TXT、2460000条节点记录。每个条件只有一份TXT。41个b是41种困境强度，**不是同一个条件的41次独立重复**。m和alpha是结构参数，不在这41个值中相互混合。

本次不重新仿真，不用收益第1列替代合作率，不把节点第5列再除以100000。对点策略个体，第5列是末期采取合作的时间比例；对边策略个体，它是“每一时刻在自身所参与超边上的合作比例”的时间平均。每个个体在类型平均中占同样权重，不按超度再加权。

## 3. A1：一个小点、一个箱体、一条线分别是什么

固定 **m=1、alpha=0、P_l=0.5**。

**第一步，在一个b条件下求同类型平均。** 真实数据b=0.5的网络有1057名点策略个体。把这些人的第5列加起来，除以1057，得到 **0.014301163671**。这就是一个蓝色小点，代表该条件下全体点策略个体的平均合作率。边策略个体另用其实际人数为分母计算橙色小点。

**第二步，对全部41个b重复计算。** 每个类型得到41个小点，再用这41个值计算箱体、中位数和上下须。箱体反映不同b下的结果分散程度，不是置信区间。

**第三步，把这41个值相加再除以41。** 得到黑色均值菱形。上述点策略箱体的均值为 **0.147199436927**，中位数为 **0.022427913810**。

**第四步，连接同类型在三个结构类别下的均值。** 蓝线连接三个点策略均值，橙线连接三个边策略均值。不同类型之间不相连，也不将41个小散点逐个连接。小散点的横向抖动只为减少遮挡；均值点、连线用箱体中心。

箱体上下边界是第25和第75百分位，中间横线是中位数。将41个值排序后，这三个量分别是第11、第31和第21个值。须延伸到1.5倍四分位距内最远的观测值；超出须的值仍在小散点中保留。合作率为0或1的条件也保留。

## 4. A2上图：所有记录合并后，计算同类型内部的占比

共同分箱为1–3、4–7、8–15、16–31、32–63、64–127、128–255、≥256。每个人只进入一个区间；最后一段没有有限上限。本批最大超度为2399，也计入≥256段。

仍固定 **m=1、P_l=0.5、点策略**，看 **超度8–15** 这一个区间：

1. 在41份b文件中分别数出超度8–15的点策略人数，然后相加，得到 **3703** 条记录。
2. 在这41份文件中分别数出全部点策略人数，然后相加，得到 **41269** 条记录。
3. 上图这一段高度为 **3703÷41269=0.089728367540，约8.973%**。

这里**不是先求每个b的百分比再平均**。分子、分母先各自相加，最后只做一次除法。

因为全部点策略记录都会落入八个区间之一，所以八段相加就是100%。边策略柱用自己的边策略总人数作为分母，也达到100%。若都改用全部点、边总人数为分母，每根柱表示的是全群体份额，而不是类型内部构成。

这些是不同b条件中的个体记录数，不是同一个网络的人数，也不能把不同TXT内相同编号的节点当作长期追踪的同一个人。纯点群体只画N柱，纯边群体只画L柱。

## 5. A2下图：每个b先算一个区间均值，再平均41个结果

仍看 **m=1、P_l=0.5、点策略、超度8–15**。

在每份TXT中，只选这个类型、这个超度区间的人。对他们的超度求算术平均，得到一个横坐标；对他们的第5列合作率求算术平均，得到一个纵坐标。下面列出5个b帮助理解，实际使用完整41个b：

| b | 同类型总人数 | 超度8–15的人数 | 区间内平均超度 | 区间内平均合作率 |
|---:|---:|---:|---:|---:|
| 0 | 1013 | 100 | 10.710000 | 0.958022 |
| 0.25 | 1045 | 99 | 9.969697 | 0.039878 |
| 0.5 | 1057 | 98 | 10.265306 | 0.004376 |
| 0.75 | 986 | 93 | 10.193548 | 0.001422 |
| 1 | 1030 | 92 | 10.434783 | 0.005208 |


例如b=0.5时，这个区间有98人，区间平均超度为10.265306，区间平均合作率为0.004376。它只代表这98人，与A1中全部1057名点策略个体的均值不同。

完成41份文件的计算后：

- 将41个区间平均超度相加，再除以41，得到 **10.21775818380**。
- 将41个区间平均合作率相加，再除以41，得到 **0.152766836513**。

所以最终画一个点 **(10.21776，0.15277)**。它代表这个区间在完整b范围内的平均表现，横坐标是实际平均超度，不是区间中点。

上图回答“全部记录中有多少比例位于这个区间”，所以合并人数；下图回答“覆盖41个b时，这个区间平均表现怎样”，所以让每个b各贡献一个均值。某个b恰好多几个人，不会提高它在下图平均中的权重。

## 7. 人数指标、缺失值和展示门槛

以上m实验点策略、超度8–15的例子：

| 指标 | 数值 | 通俗含义 |
|---|---:|---|
| n_nodes_total | 3703 | 41个b下这个区间的人数相加。 |
| n_nodes_mean | 90.317073171 | 总人数除以41，表示每个b平均有多少人。 |
| n_nodes_min | 71 | 41个b中，此区间人数最少的一次。 |
| n_type_total | 41269 | 41个b下全部点策略人数相加。 |
| node_share_pooled | 0.089728367540 | 区间总人数除以同类型总人数，上图色块高度。 |

人数均值可以有小数，因为它不是某一次仿真的人数。

下图沿用此前规则：只有在 **每个b下都至少有20个该类型个体** 的区间，才显示点线。上述区间最少有71人，因此显示。

若某个b仅有8人，即使其余条件人数很多，也不显示这个区间；若有任何一个b无人，两个下图均值留空，不填0。若41个b都有人但有的不足20，仍把候选均值保存在CSV中，`show_line=0`。中间有不合格区间时，连线断开，不跨缺口连接。

不显示的区间仍计入上图并保留数据行，不代表其合作率为0。本次m显示76个下图点，alpha显示104个。20人是保持原方法的展示门槛，不是显著性检验。

## 9. 两项结构实验的比较边界

原始生成方法从4个节点的一条超边开始，每批加入m个新节点并创建mh=3条不同超边。改变m会同时改变最终超边数量和平均超度：

| m | 超边数 | 平均超度 |
|---:|---:|---:|
| 3 | 1999 | 3.998 |
| 2 | 2995 | 5.990 |
| 1 | 5989 | 11.978 |

因此m实验不是固定平均超度的单独异质性对照。本处理保留原始差别，没有重新构图或除以网络平均超度。alpha实验固定m=1，三类均为5989条超边、平均超度11.978。

两目录共有205个m=1、alpha=0的同参数条件，完整TXT字节相同的数量为0。文件字节不同本身不等于能证明随机种子独立；本次按目录分别使用，不把它们合并或假定为重复实验。A2展示超度与合作水平的关联，不单凭这一图确认因果机制。

- 逐文件节点合作率均值与TXT全局合作率的最大绝对差为 **5.365e-09**，在原TXT八位小数的舍入误差范围内。
